# Contact reason taxonomy (starting point)

This is a first draft from the CX team. It is not complete or perfect — extend, merge or rename
categories if your reading of the messages calls for it. Just explain what you changed and why.

| Reason | Covers |
|--------|--------|
| `consulta_saldo_cuotas` | "How much do I owe / how many installments are left / what's my balance." |
| `fecha_de_pago` | Due dates, changing the payment date, days of grace. |
| `no_puede_pagar` | "I can't pay this month", hardship, asking for options. |
| `refinanciacion_acuerdo` | Asking to restructure debt / set up a payment agreement. |
| `pago_no_aplicado` | "I paid but it still shows as pending / charged twice / wrong amount." |
| `metodos_de_pago` | How/where to pay, accepted payment methods, where to send a receipt. |
| `mora_intereses` | Late interest, what happens if I'm late, late fees. |
| `reporte_centrales` | Credit-bureau reporting: "remove my negative report", "I paid, when is it updated", "you reported me by mistake." |
| `cuenta_y_app` | Login, verification codes, blocked accounts, app not working. |
| `datos_personales` | Updating phone, email or other personal data. |
| `certificados_extractos` | Requesting certificates, statements, paid-interest reports, paz y salvo. |
| `fraude_seguridad` | Suspected fraud, unrecognized charges, phishing, lost/stolen phone. |
| `queja_reclamo` | Formal complaints (PQR), poor-service escalations. |
| `felicitacion_feedback` | Compliments / positive feedback. |
| `cancelacion` | Wanting to cancel the credit / close the account. |
| `hablar_con_humano` | Explicitly asking for a human agent. |
| `fuera_de_alcance` | Not something CX handles / not related to Lumo / noise. |
