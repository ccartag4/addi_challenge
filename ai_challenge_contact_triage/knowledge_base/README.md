# Knowledge Base — Lumo CX policies

These are the policy snippets the CX team uses to answer recurring questions. They are
**incomplete and a bit inconsistent on purpose** — real internal docs are. When a message isn't
covered here, that's a signal about whether it can be safely auto-answered.

| File | Covers |
|------|--------|
| `pagos_y_cuotas.md` | Installments, balance, due dates, payment methods, prepayment |
| `mora_y_centrales.md` | Late interest, grace period, credit-bureau reporting, paz y salvo |
| `cuenta_app_seguridad.md` | Login, verification, blocked accounts, fraud and phishing |
| `datos_certificados_pqr.md` | Updating personal data, certificates/statements, complaints (PQR) |
